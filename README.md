## ✨ Key Features & User Experience

- ⚡ **Lightweight Vanilla Deck Engine:** Fast, smooth transition engine built with zero heavy runtime dependencies.
- 📱 **100% Fully Responsive Across All Devices:**
  - **Desktops & Projectors (≥ 1024px):** Strict Zero-Scroll Deck presentation mode for pitch perfection.
  - **Smartphones & Tablets (< 1024px):** Adaptive internal momentum scrolling with native **Touch Swipe Gestures** for effortless mobile slide navigation.
- 🔤 **Modern Typography:** Uses **Alexandria** for comfortable Arabic readability paired with **Plus Jakarta Sans** for crisp English terms and numbers.
- 🪟 **Interactive Modals:**
  - `CV Modal`: Quick-view technical stack, education, and achievements.
  - `Live Links Modal`: Directory of official project links and platform profiles.
  - `Image Zoom Modal`: High-resolution preview of UI screenshots and brand assets.
- ⌨️ **Keyboard Shortcuts Navigation:**
  - `←` / `Space` / `PageDown`: Next Slide
  - `→` / `PageUp`: Previous Slide
  - `F`: Toggle Fullscreen mode (⛶)
  - `Home` / `End`: Jump to First / Last Slide
  - `Esc`: Close any active modal window

   ```bash

   ```

   Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

3. **Presentation Mode:**
   Press **`F`** or click the **Fullscreen button (⛶)** in the top navigation bar for the full pitch experience.
